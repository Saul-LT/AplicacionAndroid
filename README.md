## ¿Qué hace la aplicación?

La aplicación permite al usuario iniciar sesión mediante un formulario con correo y contraseña. Solo permite el acceso si las credenciales coinciden con:
- **Correo:** `tap2025@example.com`
- **Contraseña:** `tap*2025`

Después del login exitoso, se navega a otra pantalla que muestra botones con ejercicios prácticos .

## Tipo de sistema

- Aplicación móvil Android
- Proyecto creado en **Android Studio**
- Lenguaje utilizado: **Java**
- Basado en el enfoque tradicional de múltiples actividades

## 📚 Librerías externas implementadas

Hasta el momento no se han usado librerías externas. El proyect usa únicamente dependencias estándar de Android SDK.

* AndroidX AppCompat – Para garantizar compatibilidad con versiones anteriores de Android y usar componentes modernos como AppCompatActivity.

* Material Components – Para aplicar el diseño moderno y responsivo de Material
  Design en la interfaz de usuario.

## ⚙ Requisitos técnicos

- Android Studio (recomendado: última versión)
- JDK 11 o superior
- Gradle configurado (el proyecto incluye scripts `.gradle.kts`)
- Un emulador o dispositivo Android con **API 21+**

## Pasos para instalar / ejecutar

1. Clona o descarga este repositorio:
   ```bash
   git clone https://github.com/Ingridthv/Android_Aplicacion.git
2. Abre el proyecto en Android Studio.

3. Permite que Android Studio sincronice y descargue las dependencias automáticamente.

4. Conecta un dispositivo o inicia un emulador.

5. Haz clic en Run (▶️) para compilar y ejecutar la aplicación.
