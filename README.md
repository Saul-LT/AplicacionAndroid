# LoginApp

Una aplicación Android básica que implementa una pantalla de inicio de sesión y navegación entre actividades, como parte de un proyecto de práctica.

## ¿Qué hace la aplicación?

La aplicación permite al usuario iniciar sesión mediante un formulario con correo y contraseña. Solo permite el acceso si las credenciales coinciden con:

- **Correo:** `tap2025@example.com`
- **Contraseña:** `tap*2025`

Después del login exitoso, se navega a otra pantalla que muestra botones con ejercicios prácticos.

---

## 📱 Tipo de sistema

- Aplicación móvil Android
- Proyecto creado en **Android Studio**
- Lenguaje utilizado: **Java**
- Basado en el enfoque tradicional de múltiples actividades

---

## 📚 Librerías externas implementadas

No se han usado librerías externas. El proyecto utiliza únicamente dependencias estándar de Android SDK:

- **AndroidX AppCompat:** Para compatibilidad con versiones anteriores y uso de componentes modernos.
- **Material Components:** Para aplicar el diseño moderno y responsivo de Material Design.

## ⚙ Requisitos técnicos

- Android Studio (última versión recomendada)
- JDK 11 o superior
- Gradle (ya incluido)
- Emulador o dispositivo Android con **API 21 o superior**

## ▶️ Pasos para instalar / ejecutar

1. Clona el repositorio:
   ```bash
   git clone https://github.com/Ingridthv/Android_Aplicacion.git
2. Abre el proyecto en Android Studio.

3. Espera a que se sincronicen las dependencias.

4. Conecta tu dispositivo o inicia un emulador.

5. Haz clic en Run (▶️) para compilar y ejecutar la app.
